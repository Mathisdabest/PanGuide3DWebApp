# PanGuide 3D Web App

**[Open the live app](https://huggingface.co/spaces/ilmuuu81/panguide3d)** · [Three-minute demo video](deliverables/PanGuide3D-demo-3min.mp4) · [Example PDF report](deliverables/PanGuide3D-educational-report.pdf)

PanGuide 3D is a browser-based research application for exploring AI-predicted pancreas and candidate tumor regions in CT scans. It uses the actual trained PyTorch checkpoint supplied with the PanGuide3D project. **Research and educational use only; not for clinical diagnosis or treatment.**

The app is based on **[PanGuide3D: Cohort-Robust Pancreas Tumor Segmentation via Probabilistic Pancreas Conditioning and a Transformer Bottleneck](https://arxiv.org/abs/2604.20981)**, by Sunny Joy Ma and Xiang Ma.

## Features

- NIfTI (`.nii`, `.nii.gz`) upload and ZIP archives containing a supported single DICOM CT series.
- CT validation, preserved physical geometry, and restoration of predictions to the original image grid.
- Three orthogonal CT views with slice navigation, window/level controls and adjustable overlays.
- Rotatable 3D surfaces showing pancreas-only regions, tumor-only regions and their overlap.
- Segmentation volumes, overlap statistics, scan-specific explanations and PDF/PNG exports.
- Tumor segmentation confidence calculated from actual sigmoid outputs, including each region's mean score. These are **uncalibrated model scores, not the probability of cancer**.
- Recorded Demo Results generated by a completed real model run, allowing exploration without another GPU request.
- Public Gradio deployment on Hugging Face ZeroGPU; local CPU/CUDA/Apple MPS operation where supported.

## Run locally

Use Python 3.10 and a virtual environment:

```bash
git clone https://github.com/Mathisdabest/PanGuide3DWebApp.git
cd PanGuide3DWebApp
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/fetch_weights.py
python app.py
```

Open http://127.0.0.1:7860. Accept the research/privacy notice and click **Try Sample CT / Demo Mode**. Leave **Recorded Demo Results** checked for the saved model outputs. Uncheck it for a new inference run, or upload your own de-identified research CT.

The 209 MB checkpoint exceeds GitHub's normal 100 MB file limit and is **not committed**. The fetch script retrieves the existing public file from a pinned Hugging Face Space revision and verifies SHA-256 before installation. You may instead copy the supplied file to `checkpoints/panguide3d.pt`; it must match `checkpoints/panguide3d.json`.

On a supported Apple Silicon Mac, use `PANGUIDE_DEVICE=mps python app.py` for local GPU inference. CUDA is selected automatically when available; CPU inference can be slow. Published runtime measurements are case- and hardware-specific, not guarantees.

## Example CT and recorded results

The redistributable example is [MSD Task07 pancreas_045](public-samples/MSD_pancreas_045/ct.nii.gz). The compressed file can be uploaded directly. Dataset attribution and licensing are in [public-samples/ATTRIBUTION.md](public-samples/ATTRIBUTION.md).

`demo-cache/MSD_pancreas_045.npz` contains CT data, actual predicted masks and confidence summaries from a completed model run. It does not substitute reference labels for predictions. Rebuild it with:

```bash
python scripts/build_demo_cache.py MSD_pancreas_045
```

Four unmodified PanTS scans are included under a separate dataset license (see samples/README.md). PanTS derived assets and the original bundle's Git history are excluded.

## Scientific and privacy boundaries

The network segments pancreas and candidate tumor regions; it does not establish a cancer diagnosis. An absent tumor mask does not rule out cancer. Confidence scores describe the model's label preference and can be high for incorrect predictions. Segmentation volumes are geometric model-output statistics, not validated clinical measurements.

This checkpoint's metadata identifies MSD Task07 fold 0 training. Architecture-level results from the research paper are not validation of this exact checkpoint or an individual scan. Read the audit for preprocessing and orientation limitations.

Upload only de-identified research scans. Application files and session state are temporary, with approximately 30-minute retention and periodic cleanup while the app runs. De-identification checks are incomplete, especially for burned-in text. The app has not been assessed as HIPAA-compliant.
